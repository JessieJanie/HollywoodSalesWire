# Typefully social publishing

Use Typefully v2 with a key that has PUBLISH access. `plan_at` is an inert calendar plan; only `publish_at` creates an automatic publication.

**Why:** Typefully accepted planned HSW drafts without ever publishing them. It also rejects direct publication of any X draft containing a URL, even when LinkedIn in the same draft may keep its link.

**How to apply:** Keep X copy URL-free (including short links and bare domains) while retaining LinkedIn's link. Upload images through the presigned media flow and attach the resulting media ID. Treat ambiguous provider outcomes as manual reconciliation cases—never recreate automatically without an idempotency guarantee.
